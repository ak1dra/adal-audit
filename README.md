<p align="center">
  <b>ADAL</b> (<i>адал</i> — «честный, чистый» по-казахски) — скилл для Claude, который проверяет лоты госзакупок РК,
  сверяет цены с Kaspi Магазином и с другими заказчиками и выдаёт комиссии Excel-реестр <b>только сомнительных лотов</b>
  с прямыми ссылками, основаниями в цифрах и чек-листом проверки.
</p>

---

## Что умеет

- **Массовая проверка:** до тысяч лотов по городу или области, периоду, товару и сумме. Работает без токена, через публичный реестр goszakup.gov.kz; если есть токен OWS API, использует его.
- **Рыночная цена:** медиана, минимум и число продавцов на Kaspi. Сравнение идёт только при совпадении модели или артикула, поэтому «кулер вместо сервера» в отчёт не попадёт.
- **Межлотовое сравнение:** тот же товар у других заказчиков. Работает и там, где на Kaspi аналога нет.
- **Карточка лота:** для подозрительных лотов скилл дозагружает полное ТЗ (PDF), срок поставки, всех участников с ценами и победителя из протокола итогов.
- **Оценка по факту:** если план был завышен, но торги снизили цену до рынка, лот не считается переплатой.
- **Excel для комиссии:** уровень опасности, балл 0–100, ссылки на лот, ТЗ, протокол и Kaspi, основания, чек-лист «что проверить», выпадающий статус проверки.
- **Два режима:** скрипты (Claude Code, Claude Desktop) или браузер (claude.ai, где песочница не пускает на сайты). В браузере агент запускает готовые JS-скрипты, и сотни лотов выгружаются одним вызовом.
- **Честный пустой отчёт:** если сомнительных лотов нет, Excel всё равно выдаётся, с листом «Требуют ручной проверки» для крупных лотов, которые нечем было сверить по цене.

> ⚠️ Флажок — **индикатор риска, а не доказательство нарушения**. Решение принимает комиссия после ручной проверки.

### Уровни опасности

| Уровень | Балл | Типичные признаки |
|---|---|---|
| 🔴 Критический | 75–100 | Цена победителя выше рынка на 50%+, один источник, бренд без «или эквивалент», срок < 5 дней |
| 🟠 Высокий | 50–74 | Выше рынка на 25–50%, цена не снизилась от плана, 1–2 продавца на рынке |
| 🟡 Средний | 25–49 | Наценка 10–25%, дороже, чем у других заказчиков (сверить единицы) |
| 🟢 Низкий | 0–24 | Рыночная цена, конкуренция |

## Установка

### Вариант А. claude.ai (веб или приложение Claude): проще всего

1. Скачайте архив **[`adal-audit.skill`](adal-audit.skill)** (кнопка *Download raw file*).
2. В claude.ai откройте **Настройки → Capabilities (Возможности)**:
   - включите **Code execution and file creation** (выполнение кода);
   - в разделе **Skills** нажмите **Upload skill** и выберите `adal-audit.skill`. Если `.skill` не принимается, переименуйте файл в `adal-audit.zip`.
3. Для браузерного режима установите расширение **[Claude in Chrome](https://claude.ai/chrome)**. Через него агент сам открывает goszakup.gov.kz и kaspi.kz: песочница claude.ai эти сайты не пускает.
4. Напишите в чат:
   > Проверь госзакупки г. Актау за 24–27 октября 2026

### Вариант Б. Claude Code: полный режим, тысячи лотов

```bash
git clone https://github.com/<ваш-аккаунт>/adal-audit.git
mkdir -p ~/.claude/skills
cp -R adal-audit/skills/adal-audit ~/.claude/skills/
pip install openpyxl pypdf
```

Скилл станет доступен во всех проектах. Чтобы подключить его только к одному проекту, скопируйте папку в `<проект>/.claude/skills/`. Запустите `claude` и напишите задачу обычными словами.

### Вариант В. Без ИИ, только скрипты

```bash
cd adal-audit/skills/adal-audit
pip install openpyxl pypdf
python3 scripts/check_access.py          # есть ли доступ к сайтам
python3 scripts/generate_excel_report.py \
  --region Актау --from 2026-10-24 --to 2026-10-27 \
  --live --json suspicious.json --output adal_report.xlsx
```

Требуется Python 3.9+.

## Как это устроено

```
check_access ─► режим «scripts» или «browser»
     │
1 Goszakup Auditor ─ лоты (публичный реестр / OWS API / браузер)
2 Kaspi Checker    ─ рыночные цены по уникальным моделям
  Risk Engine      ─ флажки: Kaspi, другие заказчики, процедура
  Enrich           ─ ТЗ, срок поставки, участники и победитель (для кандидатов)
  Risk Engine      ─ переоценка по фактической цене
3 Audit Reviewer   ─ ручная перепроверка топа, удаление ложных срабатываний
  Excel            ─ реестр сомнительных лотов + итоги по регионам + методология
```

## Ограничения

- Розничная цена Kaspi включает наценку. Для опта цена ниже Kaspi — норма, выше — повод проверить.
- Спецоборудования и услуг на Kaspi обычно нет: по ним работает только сравнение с другими заказчиками.
- Комплекты («4 шт., комплект» при количестве 1) пересчитываются на штуку, но формулировки в ТЗ бывают разными. Сверяйте единицы измерения.
- Если в ТЗ требуется оригинал, а на Kaspi найден совместимый аналог, сравнение некорректно. Это отлавливает шаг ручной проверки.
- Публичный реестр — это сайт, а не API: его вёрстка может измениться. Для постоянной работы лучше получить токен OWS API в АО «Центр электронных финансов».
- Сведения о поставщиках-ИП (ФИО, ИИН) берутся из открытых протоколов. Используйте их только для целей проверки.
