# Каталог Red Flags госзакупок РК

Нормативная база: Закон РК от 01.07.2024 № 106-VIII «О государственных закупках» (принципы эффективности и добросовестной конкуренции; запрет указывать товарные знаки без «или эквивалент» в техспецификации; ограниченные основания закупки из одного источника) и Правила осуществления госзакупок (приказ МФ РК). Перед ссылкой на конкретную статью в официальном документе сверяйся с актуальной редакцией на adilet.zan.kz — номера статей менялись.
